# Engenharia de Requisitos e Modelagem Agil - Agenda 09 TI I (Recuperacao)

Atividade de recuperacao da Agenda 09 da disciplina Tecnologias da Informacao I.

## Descricao

Levantamento de requisitos, modelagem de caso de uso e proposta de modelo agil para o sistema da empresa da Jessica (confeitaria artesanal Doce Encanto):
- Entrevista e simulacao de dialogo com a cliente (roleplay com IA);
- Levantamento de requisitos funcionais (RF01 a RF06) e nao funcionais (RNF01 a RNF04);
- Detalhamento formal do caso de uso "Registrar Pedido de Encomenda" (ator, objetivo, fluxo principal e excecoes);
- Diagrama UML de casos de uso;
- Proposta de desenvolvimento com metodologia agil Scrum em Sprints quinzenais.

## Estrutura de Arquivos

- `Rodrigo_Ag9_TI_I_Recup.docx`: relatorio estruturado com todos os topicos exigidos.
- `diagrama_caso_de_uso.png`: diagrama UML de casos de uso do sistema.
- `interacao_jessica.png`: registro da entrevista e alinhamento com a IA.
- `diagrama.html`: codigo-fonte do diagrama em SVG.
- `interacao_jessica.html`: transcricao visual da entrevista com a IA.
- `gerar_relatorio.py`: script de compilacao do documento docx.
- `test_validacao.py`: testes automatizados de integridade dos artefatos.

## Como Executar os Testes

```bash
python test_validacao.py
```
